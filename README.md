# 学生成绩管理与分析项目

## 项目简介
使用 Python + Pandas 完成学生成绩的创建、清洗、统计、筛选全流程。

## 技术栈
- Python 3.x
- NumPy
- Pandas

## 功能特性
- ✅ 数据创建与缺失值处理
- ✅ 总分与平均分计算
- ✅ 按班级分组统计
- ✅ 成绩筛选与排序

## 运行方式
```bash
python student_score_management.py
```

## 学习收获
- 掌握了 Pandas 数据清洗与分组统计
- 理解了缺失值处理的多种方法
